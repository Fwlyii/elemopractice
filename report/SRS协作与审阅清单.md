## 文字审阅

- [ ] 一级结构严格保持为：1 简介；2 目标、涉众分析和范围；3 业务概念分析；4 业务流程分析；5 功能性需求；6 非功能性需求；7 附录；8 版本修订记录。
- [ ] 用例描述字段采用附录 1 的术语：执行者、优先级、前置条件、基本流程、结束状况、可选流程、异常流程、说明；“验收标准”是本项目的补充字段。
- [ ] P0/P1 均为确定实现的基线，P2 明确不作为基线验收失败条件。
- [ ] 每个用例包含执行者、前置、基本流程、异常/边界、后置和可执行验收标准。
- [ ] 取消、超时、库存、支付、优惠券、积分、钱包和配送异常有唯一明确规则。
- [ ] 订单状态、配送状态、状态联动表和用例文字一致。
- [ ] 所有权限要求同时包含角色与资源归属校验。
- [ ] AI 输出不直接修改订单、库存和资产，外部服务失败有降级方案。
- [ ] 不把项目组自定目标写成课程组强制要求。

## 图片审阅

- [ ] `source/figures/srs/README.md` 中 17 张图的文件名、类型和主责人已确认。
- [ ] UML 图使用正确类型：类图、活动图、状态机图、顺序图、用例图、部署图。
- [ ] 非 UML 图只用于系统上下文、页面信息架构和界面原型。

- [ ] 每张图保留可编辑源文件和导出文件，正文中只使用 `\srsfigure`。
